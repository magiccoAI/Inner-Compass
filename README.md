# Inner Compass · 内在罗盘

> 不是急着找答案。  
> 是慢慢整理线索。

Inner Compass 是一份为**自我整理而设计的问题与书写空间**。

它不是职业测评，也不是人格测试，更不是一个会自动替你分析人生的探索工具。

它只是把一些原本很难直接回答的问题，排成一条可以慢慢走下去的路径：

**你想靠近怎样的生活？  
什么对你来说值得守住？  
哪些东西你不想慢慢习惯？  
工作应该怎样进入这份生活？  
而现在，你又站在哪里？**

但这条路径本身不会替你完成探索。

真正发生的部分，在你愿不愿意停下来，重新写一遍关于自己的东西。

---

## 这是什么

有时候，「我以后想做什么」并不是一个单独的问题。

它可能和很多还没有被分开的东西混在一起：

- 我想过怎样的生活？
- 什么对我来说真的重要？
- 有哪些未来，我不想慢慢走进去？
- 工作应该是什么样子，才能和这样的生活相容？
- 我现在的现实处境是什么？
- 我已经积累了什么？
- 还有哪些事情，我其实还不知道？

Inner Compass 做的，是把这些问题拆开，再重新放在一起。

它不会告诉你一个答案。

它更像一个**容器**：

你把自己的想法、愿望、取舍、边界、现实与猜想放进去；  
然后有机会再回头看看，它们放在一起以后，究竟留下了什么。

所以它提供的不是一个「探索结果」。

它提供的是：

> **一个可以开始、可以停下、可以回来继续写的地方。**

---

## 为什么会有 Inner Compass

Inner Compass 最开始并不是从「做一个问卷」开始的。

它来自一次关于人生选择的谈话。

当一个人站在高校、大厂、创业等不同选择面前时，真正困难的问题也许并不是：

> 「哪个选项更好？」

而是：

> **「你想拥有什么样的人生？」**  
> **「你想成为什么样的人？」**

后来，我开始尝试把这个问题做成一段普通人真的可以走进去的过程。

前置文章记录了这个项目比较早的一段制作过程：从一份文字稿出发，和 AI 一起拆问题、调整结构、修改语言，再一点点把一个很大的问题变成一份可以实际填写的 Journey。

这个仓库保存的是它继续迭代之后的公开版本。

---

## 它不负责替你探索

这个边界对 Inner Compass 很重要。

它不会：

- 算出「最适合你的职业」
- 给你贴一个人格标签
- 根据答案生成一个分数
- 判断你属于什么类型的人
- 自动把现实条件解释成限制
- 把一次尝试判断成成功或失败
- 替你决定下一步应该怎么走

甚至，它也不能保证：

> 「填写完以后，你就会更了解自己。」

因为真正的变量不是问卷，而是填写的人。

你愿不愿意停下来。

你愿不愿意重新写。

你愿不愿意认真看一遍自己写过的东西。

你愿不愿意承认：

> 有些地方我现在还不知道。

所以，Inner Compass 更像是**一个被设计过的入口和容器**，而不是一个能够独立完成探索的工具。

# 一次 Journey 会经过什么

当前公开版本为 **v5.51**，共 **7 个阶段、18 个问题**。

### 01 · 我想靠近的生活

先不谈职业。

从一个更大的生活图景开始：

如果人生往一个自己愿意靠近的方向走，它大概是什么样子？

### 02 · 把日子想具体

把抽象的愿望放进一天里。

早晨、白天、晚上，以及一天结束时希望留下的感觉。

有些事情只有落到一天里，才会第一次变得具体。

### 03 · 在意与取舍

什么值得守住？

这里不仅是列出重要的东西，也会碰到取舍：

当重要的东西不能同时被完整保留时，更想先护住什么？

### 04 · 边界与我的选择

除了看看自己想靠近什么，也看看：

**我不想慢慢走向哪里？**

这一阶段也会回看一些已经习以为常的「应该」：

它们从哪里来？  
现在还真的是自己愿意继续选择的吗？

### 05 · 从生活到工作

不是问：

> 「你适合什么职业？」

而是把前面的生活线索再往工作里翻译一步：

工作节奏、地点、协作方式、活动类型、稳定性、自主空间，以及哪些条件对自己比较重要。

### 06 · 看看现在的处境，也看看手里有什么

想过怎样的生活，和现在站在哪里，是两件不同的事。

这里会把现实放进来：

收入、地点、时间、责任、精力、已经积累的经验与资源，以及哪些条件更难调整、哪些还有空间。

现实不是裁判。

它只是坐标。

### 07 · 还有想知道的事

最后仍然不急着得出结论。

如果还有一件事情想弄清楚，可以先问：

> **为了多知道一点，我愿意先试什么？**

它可以是：

- 试一次
- 做几天
- 找个人聊聊
- 观察一阵子
- 把一个问题带进真实生活

因为有些问题，坐在桌前想不出来。

只能在现实里慢慢变清楚。

# 完成之后会看到什么

## Map Mode

Map Mode 把这一轮探索里的线索放进一张个人方向地图。

它不是人生路线规划，也不是计算出来的「人生方向」。

它只是把：

**生活图景 → 价值 → 边界 → 工作 → 现实 → 尝试**

放回同一个空间里。

你可以从不同地标进入，继续阅读背后的记录与关系。

## Record Mode

如果你想看到完整内容，可以切换到 Record Mode。

这里不会把所有东西压缩成几个关键词，而是尽可能保留你原本写下的内容。

所以：

> **Map 是一种阅读方式，Record 是完整记录。**

两者来自同一份数据，不是两套不同的结果。

---

# 试过之后

Inner Compass 不希望 Journey 在「想清楚」这里结束。

如果后来真的去试了一件事情，还可以回来记录：

- 后来实际发生了什么
- 当时想留意的信号后来怎么样
- 这次尝试之后，对原来的想法有没有变化

这里没有成功率，也没有实验评分。

「没有变化」「还是不知道」「这次没看出什么」，都可以留下来。

因为探索不一定意味着越来越确定。

有时候只是：

> **比之前更清楚地知道，自己现在还不知道什么。**

# 继续探索

结果页底部有一个可选出口：**继续探索**。

它不会直接替你生成一份 AI 分析。

而是根据你已经写下的内容，生成可以带到外部 AI 使用的阅读提示词。

当前提供两个方向：

### 深入阅读

看看这些文字放在一起后，真正出现了什么。

重点关注反复出现的线索、彼此呼应的内容、真实存在的张力，以及值得继续追问的问题。

### 寻找职业方向

不是回答：

> 「你适合什么职业？」

而是从已经写下的生活、工作与现实线索里，找出少数几个值得继续了解和验证的工作世界。

方向不是匹配结果。

验证也不是为了证明「我适合」。

而是为了获得新的信息。

Inner Compass 本身不会调用 AI API。你可以选择这次要带走哪些内容，再自行复制到 ChatGPT、Claude、Gemini 等外部 AI。

**是否把自己的记录交给外部平台，由你自己决定。**

# 从哪里开始使用

## 在线使用

如果有正式的网页入口，最简单的方式就是直接在浏览器里打开。

不需要注册账号，也不需要安装 App。

填写内容会保存在**当前浏览器的本地存储**里。页面会显示保存状态，并在修改后自动保存。

所以通常可以：

> 打开 → 写一点 → 关掉 → 以后再回来继续。

但这里有一个非常重要的特点：

**本地保存跟着浏览器和设备走，而不是跟着账号走。**

例如：

- 在 Chrome 里填写的内容，不会自动出现在 Edge
- 在电脑上填写的内容，不会自动出现在手机
- 换设备不会自动同步
- 清除浏览器网站数据可能导致本地记录消失

因此，如果准备认真完成一整轮 Journey，建议尽量固定使用：

> **同一台设备 + 同一个浏览器**

---

## 下载到自己的设备

如果你希望自己保存一份 Inner Compass，可以从 GitHub 下载项目。

最简单的方法：

1. 点击 **Code**
2. 选择 **Download ZIP**
3. 解压下载的 ZIP
4. 找到 Inner Compass 的 `.html` 文件
5. 用 Chrome / Edge / Safari / Firefox 打开

这样你就有一份属于自己的 Inner Compass。

但要注意：

> **下载 HTML，不等于把原来的填写记录一起下载下来。**

HTML 是应用本身。

你的回答保存在浏览器本地。

所以把 HTML 复制到另一台电脑重新打开，并不会自动出现原来的答案。

---

# 换设备怎么办

如果已经填写了一部分内容，又需要换设备，可以使用页面里的：

**「🔒 加密保存」**

它会在浏览器本地生成一个密码保护的备份文件。

基本流程是：

> 原设备生成备份  
> ↓  
> 自己保存备份文件与密码  
> ↓  
> 新设备打开 Inner Compass  
> ↓  
> 选择「恢复已保存的内容」  
> ↓  
> 导入备份  
> ↓  
> 输入密码

这个备份不会上传到 Inner Compass 的服务器。

加密也在浏览器本地完成。

**密码只有你知道。忘记密码，也无法替你恢复。**

# 推荐的使用方式

Inner Compass 不太适合被当成一个「做完就交卷」的问卷。

比较推荐：

### 第一次填写

找一个相对安静、不会频繁被打断的时间。

不需要提前准备正确答案。

也不需要把文字写得漂亮。

尽量写自己的话。

一句话可以。

写很多也可以。

某一道题暂时没有答案，也可以先跳过。

### 不必一次完成

你可以：

> 今天写一点 → 离开 → 过几天再回来。

有些答案会在后来变得更清楚。

有些可能会改变。

这并不意味着之前写错了。

### 完成之后

可以先看看 Map Mode。

再切到 Record Mode，把自己的完整记录重新读一遍。

有时候单独填写时没有注意到的东西，放在一起之后才会出现。

### 过一段时间

如果后来真的尝试了一件事情，再回来填写「试过之后」。

让 Compass 不只记录“我当时怎么想”，也记录：

> **现实后来告诉了我什么。**

# 桌面端与手机端

## 桌面端

第一次完整填写，**更推荐电脑或平板**。

因为：

- 开放式问题输入更舒服
- 多字段回答更容易同时查看
- Map Mode 的空间关系更容易阅读
- 完成之后查看完整 Record 更方便
- PDF / Markdown / JSON 等导出操作也更顺手

如果你准备认真走完整个 Journey，把它当成一段独立的时间，会比零碎地边做边刷手机更合适。

## 手机端

手机端同样可以使用。

它更适合：

- 临时记下一条刚想到的线索
- 补充某个问题
- 回来看之前写过的内容
- 修改已有答案
- 在现实生活中想到什么时及时记录
- 一段时间后回来填写实验回访

如果是第一次完整填写，还是更推荐桌面端。

另外，不建议在手机的隐私浏览模式里填写重要内容。

# 重要记录，建议自己带走

Inner Compass 当前提供：

- **完整记录 PDF**
- **Markdown**
- **JSON**
- **加密保存**

一个比较稳妥的方式是：

> **浏览器里填写 → 完成后导出一份 PDF / Markdown → 需要跨设备时再做一次加密保存。**

这样你不需要永远依赖某一个浏览器里的那份本地记录。

# 关于隐私

Inner Compass 的设计目标之一，是让个人记录尽量留在自己的设备上。

它没有自己的后端数据库，也不会把你的 Compass 内容发送到 Inner Compass 服务器。

但这里需要区分两件事情：

### 在 Inner Compass 里填写

记录保存在当前浏览器。

### 使用外部 AI

如果你在「继续探索」里复制了自己的内容，并主动粘贴给其他 AI 平台，那么这些内容会按照对应平台自己的规则被处理。

所以，尤其是涉及：

- 收入
- 地点
- 家庭
- 工作责任
- 身体与精力
- 其他私人经历

在复制之前，建议先看一眼这次准备带走的内容。

另外：

> **不要在公共电脑上填写私人记录。**

# 一个很重要的前提

Inner Compass 不能代替你的主动性。

如果只是快速点击、随便写几句，它可能只是一份漂亮一点的问卷。

如果你愿意真正停下来，认真回答这些问题，把一些平时很少被说出来的东西写下来，再回头看看它们放在一起是什么样子，那么它才有可能慢慢变成一份属于你的 Compass。

所以，不需要先相信：

> 「Inner Compass 能帮我找到人生方向。」

更简单一点：

> **只需要看看这些问题，是否值得你花一点时间，认真回答一次。**

剩下的部分属于你自己。

# 一些设计原则

## Reflection-first

先让人看见自己写下的东西，再谈答案。

## 生活先于职业

职业方向不是起点。

工作应该被放回一个人想过怎样的生活里理解。

## 现实是坐标，不是裁判

现实条件不会自动推翻前面的方向。

它只是告诉你：

> 现在站在哪里，手里有什么，哪些地方可以调整。

## 探索比结论重要

如果问题还没有答案，那么找到一个值得继续了解的方向，可能比得到一个漂亮的结论更有价值。

## 尽量少替人解释

保留原话、关系和线索，比急着给填写者定义一个完整的人格，更重要。

# 技术上它是什么

Inner Compass 当前是一个以 HTML 为核心的 Web 应用。

它不依赖自建后端，也不调用 AI API。

同一份 Compass 数据会被用于：

- Journey
- Compass Summary
- Map Mode
- Record Mode
- Experiment Feedback
- Export
- Continue Exploring

项目也尽量保持简单：

> 一个 HTML 文件，可以被打开、填写、保存、导出，也可以被保存到自己的设备。

它本身也是这个项目的一部分实验：

**一个原本只是文字里的问题，能不能通过一轮轮设计和迭代，变成一个别人真的可以走进去的东西。**
